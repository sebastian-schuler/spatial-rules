# Aggregation test suite: numeric oracles, coverage vs geo union, determinism

Type: task
Status: ready-for-agent
Blocked by: 01

## Question

Property + hand-checked tests over the aggregate computation:

- **Numeric aggregates**: property tests asserting `min`/`max`/`sum`/`avg` equal a brute-force scan of the applicable rules' named property (the oracle is an independent fold over the applicable set, not the engine's aggregation code); missing/non-numeric rules excluded; absent when nothing contributes.
- **Coverage**: `coverage` equals `geodesic_area(candidate ∩ union(applicable rules)) / geodesic_area(candidate)` computed directly with `geo::BooleanOps::union` + `GeodesicArea` (independent oracle); single-rule coverage equals its overlap ratio; point candidates → 0; determinism and RStar/LinearScan parity.
- **Predicate uniformity**: aggregates agree across DE-9IM, `withinDistance`, and `$activeAt` admissions (the applicable set is the same primitive).
- **Edge cases**: empty applicable set → aggregate absent; all-non-numeric applicable rules → numeric aggregates absent, count present; notMatched/invalid candidates → absent; `count`/`summary`/winner/values unchanged.
